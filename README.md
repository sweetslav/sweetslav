# 📌 Основные проекты

## 🚀 BoostCtl

Инструмент для автоматизации создания рекламных кампаний **«Буст продаж»** в Яндекс Маркете.

### Возможности

- создание отдельной кампании для каждого SKU;
- автоматическое получение внутреннего offerId;
- работа через внутреннее API;
- массовое создание кампаний;
- отчёты о выполнении;
- автоматическое формирование названий кампаний;
- повторная обработка ошибок.

**Стек**

Python • Playwright • HTTP API • JSON • Reverse Engineering

👉 https://github.com/sweetslav/BoostCtl

---

## 📊 WB Parser

Инструмент автоматического сбора аналитики Wildberries.

Позволяет ежедневно получать данные из нескольких API Wildberries и автоматически формировать отчёты в Google Sheets.

### Возможности

- статистика продаж;
- аналитика рекламы;
- показатели эффективности;
- расчёт собственных метрик;
- работа с несколькими кабинетами;
- автоматическая загрузка в Google Sheets.

**Стек**

Google Apps Script • Wildberries API • Google Sheets API

👉 https://github.com/sweetslav/wb_parser
